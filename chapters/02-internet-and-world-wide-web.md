# 🟦 Part A: The Internet

## 🌍 2.3 What Is the Internet?

### 2.3.1 English Explanation

The Internet is a worldwide system of interconnected computer networks. It allows computers, smartphones, servers and other devices to communicate and exchange data using standard communication protocols.

The word **Internet** can be understood as **interconnected networks**. It is often called a **network of networks** because it connects millions of smaller private, public, educational, business and government networks.

### 2.3.2 Hinglish Explanation

Internet duniya bhar ke computers, mobile phones, servers aur networks ko connect karne wala ek bahut bada system hai. Iski help se devices data send aur receive kar sakte hain.

Simple words me:

> Internet ek digital road network jaisa hai. Is road par websites, email, video calls, messages aur files ka data travel karta hai.

### 2.3.3 Key Definition

> [!IMPORTANT]
> **Internet:** A global network of interconnected networks that communicate using standard protocols.

---

## 🧩 2.4 Main Elements of the Internet

### 2.4.1 End Devices

These are devices used by people to connect to the Internet.

**Examples:**

- Desktop computer
- Laptop
- Smartphone
- Tablet
- Smart television
- Internet of Things devices

### 2.4.2 Network Devices

Network devices help data travel between devices and networks.

| Device | Main Work |
|---|---|
| Modem | Connects a user network to an Internet service |
| Router | Selects a path and forwards data |
| Switch | Connects devices inside a local network |
| Server | Provides data or services |
| Wireless access point | Provides Wi-Fi connectivity |

### 2.4.3 Communication Media

Data can travel through:

1. Copper cables
2. Fiber-optic cables
3. Radio waves
4. Mobile networks
5. Satellites

### 2.4.4 Protocols

Protocols are rules that devices follow while communicating.

Common protocols include:

- **TCP/IP:** Basic Internet communication
- **HTTP/HTTPS:** Web communication
- **FTP:** File transfer
- **SMTP:** Sending email
- **DNS:** Converting domain names into IP addresses

> [!NOTE]
> Protocols ko traffic rules ki tarah samjho. Rules na hon to devices ek dusre ka data properly understand nahi kar payenge.

## 🕰️ 2.5 Brief History of the Internet

| Year/Period | Development |
|---|---|
| 1960s | Packet-switching research began |
| 1969 | ARPANET connected its first computers |
| 1970s | TCP/IP concepts were developed |
| 1983 | ARPANET adopted TCP/IP |
| 1984 | Domain Name System was introduced |
| 1989 | Tim Berners-Lee proposed the World Wide Web |
| 1991 | The Web became publicly available |
| 1990s | Browsers and commercial Internet use expanded |
| 2000s | Broadband, social media and web applications grew |
| 2010s onward | Mobile Internet, cloud services, streaming, AI and IoT expanded |

### Hinglish Explanation

Internet ek hi din me nahi bana. Pehle computers ko research aur information sharing ke liye connect kiya gaya. Baad me common protocols develop hue. World Wide Web aur browsers aane ke baad Internet ordinary users ke liye easy aur popular ho gaya.

> [!WARNING]
> **Common Confusion:** Tim Berners-Lee ne Internet invent nahi kiya tha. Unhone World Wide Web propose kiya tha.

## 📡 2.6 How Do We Connect to the Internet?

### 2.6.1 Internet Service Provider

An **Internet Service Provider (ISP)** is a company or organization that provides Internet access.

**Examples in India:** Jio, Airtel, BSNL and ACT.

### 2.6.2 Common Connection Types

| Connection | Description | Common Use |
|---|---|---|
| Fiber broadband | Data through optical fiber | Homes, colleges and offices |
| Mobile data | Internet through cellular network | Smartphones and portable devices |
| Wi-Fi | Wireless connection to a local router | Homes and public places |
| DSL | Data through telephone lines | Older broadband connections |
| Cable Internet | Internet through cable network | Homes and businesses |
| Satellite Internet | Connection through satellites | Remote locations |
| Leased line | Dedicated business connection | Organizations and data centers |

### 2.6.3 Basic Connection Flow

```text
User Device → Wi-Fi/Router → ISP → Internet → Destination Server
```

### 2.7.1 World Wide Web

Used to access websites and web applications through browsers.

### 2.7.2 Email

Used to send and receive electronic messages and attachments.

### 2.7.3 File Transfer

# 🟩 Part B: World Wide Web

## 🕸️ 2.8 What Is the World Wide Web?

### 2.8.1 English Explanation

The World Wide Web, abbreviated as **WWW**, is a system of interlinked web pages and digital resources available on Internet-connected servers. Users access these resources through web browsers using URLs and HTTP or HTTPS.

### 2.8.2 Hinglish Explanation

World Wide Web linked web pages, images, videos, documents aur resources ka collection hai. Ye resources servers par stored hote hain aur browser ki help se access kiye jate hain.

### 2.8.3 Why Is It Called a Web?

Web pages hyperlinks ke through ek dusre se connected hote hain. In connected links ka structure makdi ke jaal yani **web** jaisa lagta hai, isliye ise World Wide Web kaha jata hai.

---

## 👨‍💻 2.9 Development of the World Wide Web

British computer scientist **Sir Tim Berners-Lee** proposed the World Wide Web in 1989 while working at CERN. His goal was to make information sharing between researchers easier.

The early Web was built around three major technologies:

1. **HTML** — Creates web-page structure.
2. **URL** — Provides a resource address.
3. **HTTP** — Transfers web resources.

The first website went live at CERN and explained the World Wide Web project.

---

## ⚙️ 2.10 Main Components of the Web

### 2.10.1 Web Browser

A browser requests, receives, interprets and displays web content.

**Examples:** Chrome, Firefox, Edge and Safari.

### 2.10.2 Web Server

A web server stores or generates web resources and sends them to clients.

### 2.10.3 Web Page

A web page is a single document commonly written in HTML.

### 2.10.4 Website

A website is a collection of related pages and resources under a common domain.

### 2.10.5 URL

A URL identifies the location of a web resource.

### 2.10.6 HTTP and HTTPS

These protocols define communication between browsers and web servers.

### 2.10.7 Hyperlink

A hyperlink connects one web resource to another.

---

## 🔄 2.11 How the World Wide Web Works

When a user enters a website address:

1. The browser accepts the URL.
2. DNS helps find the server's IP address.
3. The browser connects to the server.
4. The browser sends an HTTP or HTTPS request.
5. The server processes the request.
6. The server sends the requested resource or data.
7. The browser reads HTML, CSS and JavaScript.
8. The browser displays the web page.

```text
Enter URL
   ↓
Find Server
   ↓
Send Request
   ↓
Server Processes
   ↓
Receive Response
   ↓
Display Web Page
```

### Real-Life Example

Aap restaurant me menu dekhkar food order karte ho:

| Restaurant Example | Web Example |
|---|---|
| Customer | User |
| Waiter | Browser |
| Order | Request |
| Kitchen | Server |
| Prepared food | Response |
| Table presentation | Rendered web page |

## ⚖️ 2.12 Internet vs World Wide Web

| Basis | 🌐 Internet | 🕸️ World Wide Web |
|---|---|---|
| Definition | Worldwide network infrastructure | Interlinked web pages and resources |
| Nature | Network of networks | Internet service |
| Purpose | Connect devices and carry data | Share and access web content |
| Main technologies | TCP/IP, routers and network links | HTML, URL and HTTP/HTTPS |
| Access | Various Internet applications | Usually through web browsers |
| Includes | Web, email, FTP, calls and more | Websites and web applications |
| Analogy | Road network | Shops and services reached using roads |

> [!IMPORTANT]
> Internet ke bina Web access nahi kiya ja sakta, lekin Internet par WWW ke alawa bhi kai services chalti hain.

## 🔍 2.13 Browser vs Search Engine

Students often confuse a browser with a search engine.

| Browser | Search Engine |
|---|---|
| Device par installed software | Web-based search service |
| Opens websites and web pages | Finds information available on the Web |
| Example: Google Chrome | Example: Google Search |
| Example: Mozilla Firefox | Example: Bing |

### Example

Google Chrome me Google Search open kiya ja sakta hai. Yahan **Chrome browser** hai aur **Google Search search engine** hai.

## 🏢 2.14 Internet, Intranet and Extranet

### 2.14.1 Internet

A public global network that connects devices and networks worldwide.

### 2.14.2 Intranet

A private network used within an organization.

**Example:** College staff portal accessible only inside the college network.

### 2.14.3 Extranet

A controlled private network that provides limited access to authorized outsiders.

**Example:** A company portal that suppliers can access using approved accounts.

| Basis | Internet | Intranet | Extranet |
|---|---|---|---|
| Access | Public/global | Organization members | Members and authorized outsiders |
| Ownership | No single owner | One organization | One or collaborating organizations |
| Security | General Internet controls | Strong internal control | Controlled external access |
| Example | Public websites | Employee portal | Supplier portal |

## 🚀 2.15 Evolution of the Web

### 2.15.1 Web 1.0 — Read-Only Web

- Mostly static pages
- Limited user interaction
- Content created mainly by website owners
- Users mainly read information

### 2.15.2 Web 2.0 — Read and Write Web

- Social media and blogs
- User-generated content
- Comments, sharing and collaboration
- Interactive web applications

### 2.15.3 Web 3.0 — Evolving Intelligent and Decentralized Ideas

The term Web 3.0 has more than one use. It may refer to a more intelligent, connected and machine-understandable Web, and it is also sometimes used for decentralized technologies.

> [!NOTE]
> Web 3.0 ek developing concept hai. Iski ek single universally accepted definition nahi hai.

### 2.15.4 Modern Web

The modern Web also includes:

- Progressive web applications
- Cloud computing
- Artificial intelligence
- Internet of Things
- Real-time collaboration
- Mobile-first experiences

1. Internet aur WWW ko same samajhna.
2. Google Chrome ko search engine kehna.
3. Google Search ko browser kehna.
4. Har Internet service ko website samajhna.
5. ISP aur Wi-Fi ko exactly same samajhna.
6. Web 3.0 ki ek fixed definition maan lena.
7. HTTPS dekhkar website ke har claim ko automatically true maan lena.

---

## 📌 2.19 Key Points to Remember

- Internet is a **network of networks**.
- WWW is an Internet-based system of linked resources.
- ISP provides Internet connectivity.
- A browser opens and displays web resources.
- A search engine helps find Web information.
- HTML, URL and HTTP are foundational Web technologies.
- Intranet is private; Extranet provides controlled external access.
- Web 1.0 was mainly read-only, while Web 2.0 introduced greater participation.

---

## 📝 2.20 Chapter Summary

The Internet is a worldwide system that connects networks and devices using communication protocols. It supports many services, including email, file transfer, video communication and the World Wide Web. The WWW is a collection of linked web pages and resources accessed through browsers using URLs and HTTP or HTTPS. Tim Berners-Lee proposed the Web to make information sharing easier. Internet, Intranet and Extranet differ mainly in access and ownership. The Web has evolved from mostly static pages to interactive and increasingly intelligent applications.
