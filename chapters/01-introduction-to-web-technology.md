# 1. Introduction to Web Technology

## 1.1 Meaning of Web Technology

### English

Web technology refers to the tools, languages, protocols, and techniques used to create and run websites and web applications over the Internet.

### Hinglish Explanation

Web Technology ka matlab un tools, languages, protocols aur techniques se hai jinka use website aur web application banane aur Internet par chalane ke liye kiya jata hai.

## 1.2 Basic Terms

### 1.2.1 Website

A website is a collection of connected web pages available under one domain name.

**Hinglish:** Website aapas mein connected web pages ka collection hoti hai, jo ek domain name ke through open hoti hai.

### 1.2.2 Web Page

A web page is a single document displayed in a web browser.

**Hinglish:** Web page ek single document hota hai jo browser mein dikhai deta hai.

### 1.2.3 Web Application

A web application is interactive software that runs through a web browser.

**Examples:** Gmail, YouTube, online banking and shopping websites.

## 1.3 Website vs Web Application

| Website | Web Application |
|---|---|
| Mainly provides information | Allows users to perform tasks |
| Usually has limited interaction | Provides more interaction |
| Example: News website | Example: Gmail |

## 1.5 Chapter Summary

Web Technology includes all the tools and techniques used to build websites and web applications. A website contains web pages, while a web application allows users to perform interactive tasks.
