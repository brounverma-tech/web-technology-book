## 💡 1.3 Meaning of Web Technology

### 1.3.1 English Explanation

Web Technology is a collection of tools, programming languages, standards, protocols and techniques used to create, access and operate websites and web applications through the Internet or a private network.

It includes technologies such as:

- HTML for page structure
- CSS for presentation and design
- JavaScript for interaction
- Web browsers for accessing websites
- Web servers for storing and delivering content
- HTTP and HTTPS for communication
- Databases for storing application data
- Server-side languages for processing user requests

### 1.3.2 Hinglish Explanation

Web Technology un tools, languages, rules aur techniques ka collection hai jinki help se website aur web application banayi, Internet par chalayi aur browser me access ki jati hain.

Simple words me:

> Web Technology hume web pages banane, unhe attractive dikhane, user ke actions handle karne, data store karne aur Internet ke through information share karne me help karti hai.

### 1.3.3 Example

Jab hum kisi shopping website par product search karte hain:

1. HTML page ka structure dikhata hai.
2. CSS page ko design karta hai.
3. JavaScript search aur buttons ko interactive banata hai.
4. Server request ko process karta hai.
5. Database product ki information store karta hai.
6. Browser result ko screen par dikhata hai.

## 🌐 1.4 Internet and World Wide Web

### 1.4.1 Internet

#### English

The Internet is a worldwide network of interconnected computers and devices. It provides the infrastructure through which different services operate.

#### Hinglish

Internet duniya bhar ke computers aur devices ka connected network hai. Ye ek infrastructure ya raasta provide karta hai jiske through data ek device se dusre device tak pahunchta hai.

Internet पर चलने वाली कुछ services:

- World Wide Web
- Email
- File transfer
- Video calling
- Online gaming

### 1.4.2 World Wide Web

#### English

The World Wide Web, commonly called the Web or WWW, is a collection of interconnected web pages and resources accessed through the Internet using a web browser.

#### Hinglish

World Wide Web web pages, images, videos aur dusre resources ka collection hai. Hum in resources ko Internet ki help se browser me open karte hain.

### 1.4.3 Internet vs World Wide Web

| Basis | Internet | World Wide Web |
|---|---|---|
| Meaning | Global network of connected devices | Collection of web pages and resources |
| Nature | Infrastructure | Internet पर उपलब्ध service |
| Main use | Connects devices and transfers data | Provides websites and web content |
| Requirement | Uses networking hardware and protocols | Uses Internet, browser, HTTP/HTTPS and URLs |
| Example | The road network | A service running on those roads |

> [!IMPORTANT]
> **Remember:** Internet aur WWW same nahi hain. Web, Internet par chalne wali ek service hai.

## 📖 1.5 Important Web Terms

### 1.5.1 Web Page

#### English

A web page is a single digital document available on the Web. It is commonly created using HTML and displayed by a web browser.

#### Hinglish

Web page ek single digital document hota hai jo browser me open hota hai. Jaise kisi book me ek page hota hai, waise hi website me ek web page hota hai.

**Examples:** About page, Contact page and Login page.

### 1.5.2 Website

#### English

A website is a collection of related web pages and resources available under a common domain name.

#### Hinglish

Website related web pages ka collection hoti hai. Ye pages usually ek hi domain name ke under available hote hain.

**Examples:** Wikipedia, Amazon and a college website.

### 1.5.3 Home Page

#### English

The home page is the main or starting page of a website. It usually provides links to the important sections of the website.

#### Hinglish

Home page website ka main ya starting page hota hai. Yahin se user website ke dusre sections me ja sakta hai.

### 1.5.4 Web Application

#### English

A web application is software that runs on a web server and allows users to perform interactive tasks through a browser.

#### Hinglish

Web application aisa software hai jise browser ke through use kiya jata hai. Isme user sirf information nahi padhta, balki login, search, booking, payment aur data entry jaise tasks bhi karta hai.

**Examples:** Gmail, Google Docs, online banking and student portals.

### 1.5.5 Web Browser

A web browser is client software used to request, receive and display web content.

**Examples:** Google Chrome, Mozilla Firefox, Microsoft Edge and Safari.

### 1.5.6 Web Server

A web server is a computer or software that stores web resources, accepts client requests and sends responses.

**Examples of server software:** Apache, Nginx and Microsoft IIS.

### 1.5.7 URL

URL stands for **Uniform Resource Locator**. It is the address of a resource available on the Web.

Example:

```text
https://example.com/about.html
```

In this URL:

- `https` is the protocol.
- `example.com` is the domain name.
- `about.html` is the resource path.

### 1.5.8 Hyperlink

A hyperlink is a clickable text, image or element that takes the user to another page, file or section.

## 🧩 1.6 Basic Components of Web Technology

### 1.6.1 Client

The client is a device or program that requests a service. A browser commonly acts as a web client.

**Hinglish:** Client request bhejta hai. Jab aap browser me website open karte ho, browser client ki tarah work karta hai.

### 1.6.2 Server

The server receives the client's request, processes it and returns a response.

**Hinglish:** Server client ki request receive karke required page ya data wapas bhejta hai.

### 1.6.3 Communication Protocol

A protocol is a set of rules used for communication between devices.

The Web mainly uses:

- HTTP — Hypertext Transfer Protocol
- HTTPS — Hypertext Transfer Protocol Secure

### 1.6.4 Front End

The front end is the part of a website that users can see and interact with.

Main front-end technologies:

1. HTML
2. CSS
3. JavaScript

### 1.6.5 Back End

The back end works on the server. It processes requests, applies application logic and communicates with a database.

Common back-end technologies include PHP, Java, Python, Node.js and .NET.

### 1.6.6 Database

A database stores organized data used by a web application.

**Examples:** Student details, login records, product information and orders.

## 🔄 1.7 How a Website Works

When a user opens a website, the following basic steps occur:

1. The user enters a URL in the browser.
2. The browser finds the website's server address.
3. The browser sends an HTTP or HTTPS request.
4. The web server receives the request.
5. The server processes the request.
6. If required, the server reads data from a database.
7. The server sends a response to the browser.
8. The browser renders the received content on the screen.

### Simple Flow

```text
User → Browser → Request → Web Server → Response → Browser → Web Page
```

### Hinglish Explanation

User browser me address enter karta hai. Browser server ko page ki request bhejta hai. Server request process karke HTML, CSS, JavaScript ya data return karta hai. Browser us response ko readable page ke form me screen par show karta hai.

## ⚖️ 1.8 Static and Dynamic Websites

### 1.8.1 Static Website

A static website displays mostly fixed content. Its pages usually show the same content to every visitor until a developer manually changes the files.

**Examples:** Simple portfolio and basic information website.

### 1.8.2 Dynamic Website

A dynamic website can generate or change content according to the user, stored data, time or user action.

**Examples:** Social media, e-commerce website and student portal.

### 1.8.3 Difference Between Static and Dynamic Websites

| Basis | Static Website | Dynamic Website |
|---|---|---|
| Content | Mostly fixed | Can change automatically |
| Interaction | Limited | High |
| Database | Usually not required | Commonly required |
| Development | Simpler | More complex |
| Speed | Usually faster | Depends on processing |
| Example | Basic portfolio | Online shopping website |

|---|---|---|

| Example | News or information site | Gmail or online banking |

> [!NOTE]
> Modern websites often include application-like features, so the boundary between a website and a web application is not always strict.

## ✅ 1.12 Advantages of Web Technology

1. **Global access:** Web resources can be accessed from different locations.
2. **Easy communication:** Information can be shared quickly.
3. **Platform independence:** Many web applications work on different operating systems.
4. **Centralized updates:** Developers can update the server without reinstalling the application on every device.
5. **Interactive services:** Users can study, shop, communicate and work online.
6. **Cost effectiveness:** Web solutions can reduce printing, communication and distribution costs.
7. **Scalability:** Applications can be expanded for more users and features.

## ⚠️ 1.13 Limitations and Challenges

1. Many web services require an Internet connection.
2. Slow connections can reduce performance.
3. Websites may face security and privacy risks.
4. Different browsers may display content differently.
5. Server failure can make a service unavailable.
6. Poor design can create accessibility problems.
7. Regular maintenance and updates are required.

## 🧪 1.14 First HTML Example

HTML is used to create the structure of a web page.

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Web Page</title>
</head>
<body>
    <h1>Welcome to Web Technology</h1>
    <p>This is my first web page.</p>
</body>
</html>
```

### Explanation

1. `<!DOCTYPE html>` declares an HTML5 document.
2. `<html>` is the root element.
3. `<head>` contains page information.
4. `<title>` sets the browser-tab title.
5. `<body>` contains visible page content.
6. `<h1>` creates a main heading.
7. `<p>` creates a paragraph.

Detailed HTML will be covered in later chapters.

## 🚫 1.15 Common Mistakes

1. Treating the Internet and WWW as the same thing.
2. Calling every web page a complete website.
3. Confusing a browser with a search engine.
4. Assuming that all websites are web applications.
5. Believing that HTML is a programming language.
6. Ignoring security, accessibility and mobile users.

## 📌 1.16 Key Points to Remember

1. Internet is a global network; the Web is a service that uses it.
2. A web page is one document, while a website is a collection of related pages.
3. A browser acts as a client and requests resources from a web server.
4. HTML, CSS and JavaScript are the main front-end technologies.
5. Back-end technologies process requests and work with databases.
6. HTTP and HTTPS define how web clients and servers communicate.
7. Static sites show mostly fixed content; dynamic sites can generate changing content.

---

## 📝 1.17 Chapter Summary

Web Technology includes the tools, languages, protocols and methods used to create and operate websites and web applications. The Internet provides the worldwide network, while the World Wide Web provides linked pages and resources through that network. A browser sends a request to a server, and the server returns a response. HTML, CSS and JavaScript form the front end, while server-side technologies and databases support the back end. Websites may be static or dynamic and are used in education, business, banking, communication, entertainment and many other fields.
