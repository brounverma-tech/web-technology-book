# BCA Web Technology Syllabus

## Course Level

**Beginner to Advanced**

## Prerequisites

No previous knowledge of programming or web development is required.

## Learning Objectives

After completing this book, a learner will be able to:

1. Explain how the Internet and the Web work.
2. Create structured web pages using HTML.
3. Design responsive interfaces using CSS and Bootstrap.
4. Add logic and interactivity using JavaScript.
5. Use Git and GitHub for version control.
6. Develop server-side programs using PHP.
7. create and manage MySQL databases.
8. Build database-driven web applications.
9. Work with AJAX, JSON, XML and REST APIs.
10. Apply basic web security, accessibility, SEO and performance practices.
11. Build and publish a complete full-stack project.

## Chapter Format

Every chapter will contain:

1. Learning objectives
2. Difficult words with pronunciation and meaning
3. English explanation
4. Simple Hinglish explanation
5. Definitions and key points
6. Syntax and practical examples
7. Common mistakes
8. Chapter summary
9. Practice exercises
10. Viva and exam questions

## Suggested Practical Projects

1. Personal profile page
2. Registration form
3. Responsive portfolio website
4. JavaScript calculator
5. To-do application
6. PHP contact form
7. Student record system using PHP and MySQL
8. Final full-stack BCA project
