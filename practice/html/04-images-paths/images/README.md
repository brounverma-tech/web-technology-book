# Add Your Image Here

Apni local practice mein koi image is folder ke andar rakho.

Recommended filename:

```text
my-photo.jpg
```

Agar image PNG hai:

```text
my-photo.png
```

Filename aur HTML ke `src` attribute ka naam exactly match hona chahiye. Personal photo ko public GitHub repository mein upload karne se pehle privacy zaroor consider karo.
