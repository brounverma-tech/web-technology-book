## Important Rules

- One clear `h1` use karo.
- Section headings ke liye `h2` use karo.
- Navigation links ke `href` aur section `id` match hone chahiye.
- Images ke saath meaningful `alt` text rakho.
- Lists ke items `li` mein rakho.
- Table ki har row mein equal cells rakho.
- Form labels ka `for` matching input `id` se connect karo.
- Real private information form testing mein mat use karo.
- Abhi CSS mat lagao; pehle correct HTML structure complete karo.
