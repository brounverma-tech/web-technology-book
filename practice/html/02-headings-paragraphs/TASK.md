# Practical 02: Headings and Paragraphs

## Goal

Is practical mein tum headings ki levels aur paragraphs ka use samjhoge.

## Related Theory

Read: [Chapter 7 — HTML Fundamentals](../../../chapters/07-html-fundamentals.md)

`frontend-practice` ke andar naya folder banao:

```text
frontend-practice/

    └── index.html
```

## Step 2: Code Type Karo

GitHub par diya gaya [index.html example](index.html) apni local file mein khud type karo.

## Step 3: Apni Changes Karo

Example chalne ke baad:

1. **My City** ke paragraph mein apne city ka naam likho.
2. **My Hobby** ke paragraph mein apni hobby likho.
3. Ek nayi `<h2>` heading **My Future Goal** add karo.
4. Us heading ke neeche apna goal ek `<p>` mein likho.

## Tag Meaning

| Tag | Use |
|---|---|
| `<h1>` | Page ki sabse important main heading |
| `<h2>` | Main section ki heading |
| `<h3>` | Section ke andar chhoti heading |
| `<p>` | Normal paragraph |
| `<br>` | Same paragraph ke andar line break |

## Rules

- Ek page par generally ek clear `h1` rakho.
- Heading level ko order mein use karo: `h1`, phir `h2`, phir zarurat par `h3`.
- Sirf text bada karne ke liye heading tag mat use karo.
- Har paragraph ke liye `<p>...</p>` use karo.
