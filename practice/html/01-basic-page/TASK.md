# Practical 01: Basic HTML Page

## Goal

Is practical mein tum HTML document ka basic structure banaoge aur samjhoge ki browser mein visible content kahan likha jata hai.

## Related Theory

Read: [Chapter 7 — HTML Fundamentals](../../../chapters/07-html-fundamentals.md)

## Step 1: Local Folder Banao

VS Code mein:

1. `frontend-practice` folder open karo.
2. Uske andar `practical-01` folder banao.
3. `practical-01` ke andar `index.html` file banao.

## Step 2: Starter File Dekho

GitHub par diya gaya [starter index.html](index.html) dekho. Same structure ko apni local file mein **khud type** karo.

## Step 3: TODO Tasks Complete Karo

`<body>` ke andar:

1. Ek main heading likho: **Broun's HTML Practice**
2. Ek paragraph likho: **I am learning HTML step by step.**
3. Ek second-level heading likho: **My Goal**
4. Apna learning goal ek paragraph mein likho.
5. Ek horizontal line add karo using `<hr>`.
6. Code mein ek HTML comment likho.

## Expected Browser Output

Browser mein ye content dikhna chahiye:

- Broun's HTML Practice
- I am learning HTML step by step.
- My Goal
- Tumhara learning goal
- Ek horizontal line

`head`, `title`, `meta` aur HTML comment browser page par visible nahi honge.

## Self-Check

- [ ] File ka naam `index.html` hai.
- [ ] `<!DOCTYPE html>` sabse upar hai.
- [ ] `<html>`, `<head>` aur `<body>` sahi jagah hain.
- [ ] Opening aur closing tags match karte hain.
- [ ] Har tag ka closing `>` laga hua hai.
- [ ] File save karke browser refresh kiya hai.

## Common Mistakes

- `<title>` ko `body` mein likhna
- Closing tag bhoolna
- Tag ke end mein `>` bhoolna
- File ko `index.html.txt` ke naam se save karna
- Code change karne ke baad browser refresh na karna
