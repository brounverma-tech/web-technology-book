# HTML Practical Track

This track is for learning HTML by writing code step by step.

**Theory:** [Unit 2: HTML](../../SUMMARY.md#unit-2-html)  
**Author and learner:** Broun Verma

## How to Study

Har practical ke liye ye process follow karo:

1. Related theory ko thoda padho.
2. VS Code mein code khud type karo.
3. File save karo using `Ctrl + S`.
4. Browser refresh karke output dekho.
5. Error aaye to tags, spelling aur closing brackets check karo.
6. Apna code ya screenshot checking ke liye share karo.
7. Practical complete hone ke baad GitHub par commit karo.
