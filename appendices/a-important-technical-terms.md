# 14. 📝 Commonly Confused Terms

| Term 1 | Term 2 | Difference |
|---|---|---|
| Internet | Web | Internet network infrastructure; Web us par one service |
| Website | Web Page | Website pages ka collection; page single document |
| Domain | URL | Domain site name; URL complete resource address |
| HTTP | HTTPS | HTTPS TLS-protected HTTP |
| Client | Server | Client request; server response/service |
| HTML | CSS | HTML structure; CSS presentation |
| Element | Tag | Element complete component; tag markup marker |
| Margin | Padding | Margin outside; padding inside border |
| ID | Class | ID usually unique; class reusable grouping |
| `==` | `===` | Loose vs strict JavaScript equality |
| Parameter | Argument | Definition input name vs actual call value |
| Front End | Back End | Browser UI vs server logic/data |
| Cookie | Session | Cookie browser value; session server-side state concept |
| Authentication | Authorization | Identity vs permission |
| Encryption | Hashing | Reversible with key vs one-way |
| Validation | Sanitization | Rule checking vs risky content transform/clean |
| SQL Injection | XSS | Database query injection vs browser content injection |
| Primary Key | Foreign Key | Unique row identity vs referenced relationship |
| DELETE | DROP | Rows remove vs database object remove |
| WHERE | HAVING | Rows before grouping vs groups after grouping |

| JSON | XML | Key/array data vs element/attribute hierarchy |
