## 🎯 Answer-Writing Strategy

### 2-Mark Answer

- exact definition/full form;
- 2 key points;
- one small example if space.

### 5-Mark Answer

1. definition;
2. working/purpose;
3. 4–5 points;
4. short example/diagram;
5. conclusion.

### 10-Mark Answer

1. introduction;
2. detailed explanation with headings;
3. diagram/table;
4. syntax/code;
5. example/output;
6. advantages/limitations/security;
7. conclusion.

### Code Question

- aim/logic;
- clean indentation;
- meaningful names;
- validation/error handling;
- important comments;
- expected output;
- security where relevant.
