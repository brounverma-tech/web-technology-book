# ⚖️ Commonly Confused Terms

| Terms | Main Difference |
|---|---|
| **Internet vs WWW** | Internet global network hai; WWW us network par available webpages ka system hai. |
| **Webpage vs Website** | Webpage single document hai; website related webpages ka collection hai. |
| **HTML vs CSS** | HTML structure banata hai; CSS presentation aur layout control karta hai. |
| **Front End vs Back End** | Front end user ko dikhta hai; back end server, logic aur database handle karta hai. |
| **HTTP vs HTTPS** | HTTPS, HTTP communication ko TLS encryption se secure karta hai. |
| **Tag vs Element** | Tag markup symbol hai; element tags, attributes aur content ka complete unit hai. |
| **Attribute vs Property** | Attribute HTML me initial value deta hai; property DOM object ki current value hoti hai. |
| **Class vs ID** | Class reusable hoti hai; ID page par ideally unique hoti hai. |
| **Authentication vs Authorization** | Authentication identity check karti hai; authorization permissions decide karti hai. |
| **Cookie vs Session** | Cookie client browser me store hoti hai; session data normally server par store hota hai. |
| **GET vs POST** | GET mainly data read karta hai; POST server ko data submit/create karta hai. |
| **Primary Key vs Foreign Key** | Primary key own row ko identify karti hai; foreign key tables ko relate karti hai. |
| **DELETE vs TRUNCATE vs DROP** | DELETE rows remove, TRUNCATE all rows clear, aur DROP complete table remove karta hai. |
| **Library vs Framework** | Library ko code call karta hai; framework application flow ko control karta hai. |
| **Git vs GitHub** | Git local version-control tool hai; GitHub online Git hosting platform hai. |
| **JSON vs XML** | Dono data formats hain; JSON usually compact hai, XML tag-based aur more descriptive hai. |
| **Bug vs Error vs Exception** | Bug code defect hai, error general failure hai, exception handle ki ja sakne wali runtime condition hai. |
| **Responsive vs Adaptive Design** | Responsive layout fluidly adjust hota hai; adaptive design fixed layouts me switch karta hai. |
